# 组件与视觉规范 · 一套结构规则，全局统一

> 适用对象：本项目纯静态 HTML 大屏（指挥 / 生产 / 参观等，独立 HTML 文件，单页内联 `<style>` 与 `<script>`，内联 SVG 图形，无图表库、无组件库）。
> 本文只规定「结构、尺寸、排印、交互与取色」的统一规则——所有大屏共用同一套；差异只允许出现在令牌取值（色相、圆角、密度、阴影）上，结构、命名和交互不得分叉。换风格 = 换一组令牌值，不改业务代码。
> 表格中「本项目取值 / 随风格变化」列：给出深蓝大屏当前实际值；括号内为允许随风格切换的变体，未标注即为全局固定。

## 表 A · 设计令牌（尺寸与排印）

| 令牌 | 规范值 | 本项目取值 / 随风格变化 |
|---|---|---|
| 字号 | 正文 14px；面板标题 18px / 600；次级数值 24px；关键 KPI 28px / 700；页面主标题 32px / 700；角标 12px。只用 12 / 14 / 16 / 18 / 20 / 24 / 28 / 32 阶梯，禁止 13 / 15 / 17 / 19 / 22 / 26 混排 | 全局固定（大屏等比缩放，字号随画布缩放，不单独放大） |
| 字距 | 中文标题 `letter-spacing: 4~6px`；标签与说明 `0.5px`；数字与单位 `0.5px`，百分比紧贴数字 | 全局固定 |
| 行高 | 正文与标签 1.5；标题 1.2；大数字 1.15 | 全局固定 |
| 控件高度 | 按钮 / 页签 / 下拉统一一档：大屏 36px（弹窗内 32px），禁止 28 / 32 / 36 混用于同一区域 | 36px（弹窗 32px） |
| 圆角 | 面板与数据区 2px；控件、下拉、弹窗 4px；角标标签 2px。禁止 ≥ 8px（科技风偏锐利） | 面板 2px / 控件 4px |
| 表格 / 列表行高 | 表头 38px；数据行按内容固定、不随字数撑高；行内最多两行文字 | 全局固定（大屏少用表格，优先卡片） |
| 间距 | 统一 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。面板内边距 16（紧凑 12）；卡片 gutter 16；段间距 12 | 全局固定 |
| 主色 | 全站唯一强调色，主按钮、选中态、链接、焦点、图表主色同源，禁止第二强调色 | `--brand-cyan` `#6FDCEA` |
| 底色 / 面板 | 页面底色、面板底、边框、文字各一档，禁止多套深蓝渐变并存 | 底 `#0E3862`；面板 `rgba(27,72,110,.55)`；次要字 `#BFD4E2` |
| 状态色 | 成功 / 警告 / 危险 / 信息 / 中性，共 5 类，禁止自造新色；状态浅底用 `rgba(状态色,.14)` 派生 | 成功 `#4FD69B`、警告 `#F0B75A`、危险 `#FF5D6C`、信息 `#6FDCEA`、中性 `#A7C0CE` |
| 阴影 / 发光 | 仅卡片与弹窗使用阴影；发光只用主色一档，禁止大面积泛光；列表内不叠阴影 | 弹窗 `0 0 40px rgba(0,0,0,.5)`；主色发光 `rgba(111,220,234,.5)` |
| 边框 | 面板 1px `--border-base`；内部分隔 1px `--border-soft`；同处不叠双线、分隔线不重复 | `rgba(150,205,220,.42)` / `.22` |

## 表 B · 组件统一规则（结构 / 交互）

| 组件 | 统一规则 |
|---|---|
| 按钮 | 只保留「主 / 次 / 文字 / 危险」四类；同一区域主按钮 ≤ 1 个；行内操作只用文字按钮；危险操作需二次确认。高 36 / 圆角 4 / 字号 14；hover 主色描边，禁用态降透明度 |
| 页签 Tab | 高 36 / 圆角 4 / 字号 16；选中态主色边框 + 内发光，未选中 `--text-secondary`；一组页签同时只有一个选中 |
| 下拉选择 | 高 36 / 圆角 4 / 边框 `--border-soft`；展开菜单底 `--bg-elevated`，项字号 14，hover 主色；点击外部或 ESC 收起 |
| 文字按钮（详情） | 字号 14 / `--text-secondary`，hover 变主色，无边框；只用于打开详情，不做破坏性操作 |
| 面板（卡片） | 结构 = 标题栏（40px）+ 内容区（flex:1）；标题 18 / 600 + 统一菱形角标；内容区 padding 16（紧凑 12），段间距 12；同类面板标题栏高度、字号、内边距、圆角必须一致 |
| 状态标签 | 五类语义固定映射：待处理 warning、处理中 info、已完成 success、高风险 danger、已归档 default；只换文案不换配色；浅底 `rgba(状态色,.14)` + 状态色文字 |
| 输入控件 | 默认 / 错误 / 禁用 / 只读四态；高度 / 圆角 / 边框与按钮同源；错误态红边 + 下方说明；只读态降 45% 透明度；数字单位紧贴数值 |
| 提示条 | 信息 / 成功 / 警告 / 危险四档；左侧 3px 状态色竖条 + 浅色底 + 状态色文字；同一屏同类提示样式一致 |
| 空态 | 三段式：图形占位 + 主说明 + 次要引导；无数据时禁止留白，统一显示「暂无数据」 |
| Toast | 底部居中；字号 14；深底 + 主色边框；约 2s 自动消失；同类反馈不叠多个 Toast |
| 弹窗 | 详情图按内容定宽（本项目 1740px 上限）；标题栏 44px / 18px；内容 padding 12；遮罩 `--bg-mask`；点遮罩或 ESC 关闭；内容超高时独立滚动 |
| **柱状图** | 柱宽固定、柱间距 = 柱宽的 1/2；系列色按 `--chart-1→4` 顺序取，同一图内不随机换色；基线用 `--border-soft`；圆角仅柱顶 2px；数值标签字号 12 置于柱顶，单位在轴标题统一标注；禁止 3D、渐变堆叠、双轴无标识 |
| **条形图** | 与柱状图同源，仅方向旋转；类别名左对齐、数值右对齐；横向滚动时首类别固定 |
| **折线图 / 面积图** | 线宽 2；面积填充用 `--chart-1` 透明度 ≤ .16；拐点默认不加圆点，仅离散值加；多条线靠颜色 + 线型（实 / 虚）双重区分，不只靠颜色；网格线 `--border-soft` 透明度 ≤ .12；面积图必须在 0 基线闭合 |
| **饼图** | 扇区按 `--chart-1→4` 顺序取色，相邻扇区色差 ≥ 1 档；扇区间留 1px `--bg-panel` 间隙；占比 > 5% 的扇区带标签（名称 + 百分比），小占比并入「其他」；从 12 点方向顺时针起画 |
| **环形图** | 环宽固定（外径的 1/6~1/8）；起始角 12 点；中心显示主数值（24px）+ 单位（12px）；分段色序、间隙、标签规则同饼图；空数据环用 `--chart-track` |
| **仪表盘 / 半环** | 轨道 `--chart-track`，值弧 `--chart-1`；弧端圆头；中心数值 24px `--text-primary`，单位 12px；阈值分段只用状态色，不超过 3 段 |
| **进度条** | 高 8~10px / 圆角 4；轨道 `rgba(主色,.13)`，填充主色渐变；百分比数字紧贴条右侧或上方；多段进度按状态色映射，不新造色 |
| **散点 / 气泡图** | 点用主色 `.7` 透明度，选中态实心 + 主色描边；点大小映射单一维度并在图例说明；禁止用颜色同时编码两个含义 |
| **雷达图** | 轴线 `--border-soft`；多边形填充主色 ≤ .14、描边主色；多个系列用 `--chart-1/2` + 透明度区分；维度名沿轴外侧对齐 |
| 图表通用 | 所有图表：标题左对齐、图例置顶或右下且不压图形、单位必标、空数据显示「暂无数据」；同一大屏内同类图表尺寸、内边距、字号一致；取色只走 `--chart-*` 与状态色 |

## 组件规范陈列（全局统一实现的示例）

> 以下为本项目深蓝大屏令牌下的标准实现。换风格时只替换令牌值，结构与文案不变。

### 色彩令牌

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--brand-cyan` | `#6FDCEA` | 主色 / 面板 / 边框 / 强调文字 |
| `--bg-topbar` | `#1C4670` | 顶栏渐变起色 |
| `--bg-page` | `#0E3862` | 页面底色 |
| `--bg-panel` | `rgba(27,72,110,.55)` | 面板底 |
| `--border` | `rgba(150,205,220,.42)` | 边框 |
| `--text` | `#EAF6FF` | 主文字 |
| `--success` | `#4FD69B` | 成功 |
| `--warning` | `#F0B75A` | 警告 |
| `--danger` | `#FF5D6C` | 危险 |
| `--chart-1` / `--chart-2` | `#6FDCEA` / `#3E86B4` | 图表系列 1 / 2 |

### 按钮体系（主 / 次 / 文字 / 危险 / 禁用）

| 主按钮 | 次按钮 | 文字按钮 | 危险按钮 | 禁用 |
|---|---|---|---|---|
| 主色边框 + 提亮底 | `--border-soft` 边框 | 无边框、次要色 | 危险色边框与文字 | 降 45% 透明度 |

示例：`数字孪生` `详情` `视角归位` `停止漫游（危险）` `提交（禁用）`；页签与按钮同高同圆角，小号按钮用 14px 字号。

### 状态标签（五类语义固定）

| 待处理 | 处理中 | 已完成 | 高风险 | 已归档 |
|---|---|---|---|---|
| warning `#F0B75A` | info `#6FDCEA` | success `#4FD69B` | danger `#FF5D6C` | default `#A7C0CE` |

示例：`待复检 6 件` `逾期 4 单` `达标` `高风险` `已归档`——只换文案不换配色。

### 输入控件（默认 / 错误 / 禁用 / 只读 / 下拉）

| 默认态 | 错误态 | 只读 / 禁用 | 下拉选择 |
|---|---|---|---|
| 边框 `--border-soft`、高 36 | 危险色边框 + 下方说明 | 降 45% 透明度 | 高度 / 圆角 / 边框与按钮同源 |

### 提示条（信息 / 成功 / 警告 / 危险）

| 级别 | 示例文案 |
|---|---|
| 信息 | 左键旋转 · 中键平移 · 滚轮缩放 |
| 成功 | 默认视角已保存 |
| 警告 | 距计划 6 件，达成 84.2% |
| 危险 | 风险设备 2 台，请及时处理 |

### 空态（三段式）

图形占位（描边图标）→ 主说明「暂无数据」→ 次要引导「请检查筛选条件或稍后刷新」。三行等高居中，禁止只留空白。

### 图表陈列（柱状 / 折线 / 饼 / 环形 / 仪表 / 进度）

| 图表 | 关键实现 |
|---|---|
| 柱状图 | 柱间距 = 柱宽 1/2；顶圆角 2px；系列色 `--chart-1→4`；轴标题标单位 |
| 折线 / 面积 | 线宽 2；填充 ≤ .16；多线靠颜色 + 线型区分；面积收于 0 基线 |
| 饼图 | 色序固定；1px 间隙；>5% 带标签，其余并入「其他」；12 点顺时针起画 |
| 环形图 | 环宽 = 外径 1/6~1/8；中心 24px 主数值 + 12px 单位；空环 `--chart-track` |
| 仪表盘 | 轨道 `--chart-track`，值弧 `--chart-1`，圆头；阈值分段 ≤ 3 段 |
| 进度条 | 高 8~10 / 圆角 4；百分比紧贴条侧；多段按状态色映射 |

## 自检清单

| 检查项 | 通过标准 |
|---|---|
| 令牌唯一 | 业务样式区裸 hex = 0，全部走 `var(--*)` |
| 字号 / 间距 / 圆角 | 字号落在 12/14/16/18/20/24/28/32；间距为 4 倍数；圆角仅 2/4 |
| 面板结构 | 标题栏 40px / 18 / 600 + 统一菱形角标；内边距 16 |
| 图表取色 | 全部走 `--chart-*` / 状态色；同类图表尺寸、内边距、字号一致 |
| 状态语义 | 五类状态色映射唯一，未自造新色 |
| 文案 | 无制作说明式文字，数字与单位规范 |
| 交互一致 | 弹窗 / 下拉 / 页签 / 按钮行为与本规范一致 |
