# 大屏系统全局 UI 规范（纯静态 HTML 原型版）

> 适用范围：本项目为**纯静态 HTML 原型**——每个大屏界面是一个独立 HTML 文件，页面内自带 `<style>` 与 `<script>`，图片放在各自屏的 `assets/images/`，不使用任何构建工具、UI 库、图表库或组件库，数据全部为 Mock。
> 本规范用于统一各独立大屏的视觉，不引入新依赖，不改变现有目录结构与交互逻辑。
> 说明：本文件只定义规范与 tokens，改造业务页面按后续指令逐页进行。

---

## 第 0 章 技术栈与适用范围

| 项 | 结论 |
|---|---|
| 页面形态 | 独立 HTML 文件，一屏一文件，存放于各 `* _screens/pages/` 下 |
| 样式组织 | 单页 `<style>` 内联；设计 token 集中在该页 `:root`，业务样式只引用 `var(--*)` |
| 脚本 | 原生 JavaScript，内联 `<script>`；Mock 数据写在脚本或 DOM 中 |
| 图形 | 图片素材 + 内联 SVG（折线、仪表、进度），**无 ECharts 等图表库** |
| 缩放 | 设计画布等比缩放（如 2600×800，按 `min(innerWidth/W, innerHeight/H)` 计算 `--s`），不改布局百分比规则 |
| 依赖 | 禁止引入任何新库、框架、图标库、CSS 框架 |
| 色值来源 | 从现有页面归并，不新造色；确需新增时按最近似原则派生并标注 `derived` |

### 0.1 色值硬约束

业务样式区**禁止出现裸 hex 色值**；所有颜色必须在 `:root` 定义为 token 后以 `var(--*)` 引用。
例外（视为图形素材，不计入）：SVG 内联图形的 `stroke`/`fill` 若需随主题变化，也应使用 `var(--*)`。

## 第 1 章 设计 Tokens

### 1.1 颜色（归并自现有三屏，按语义命名）

| token | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#0E3862` | 大屏页面底色 |
| `--bg-deep` | `#0B2C47` | 模型/画面容器深底 |
| `--bg-panel` | `rgba(27,72,110,.55)` | 面板半透明底 |
| `--bg-panel-hover` | `rgba(62,134,180,.45)` | 面板/按钮悬浮底 |
| `--bg-elevated` | `#0F3C5E` | 弹窗等浮层底 |
| `--bg-mask` | `rgba(6,26,48,.78)` | 遮罩 |
| `--border-base` | `rgba(150,205,220,.42)` | 面板边框 |
| `--border-soft` | `rgba(150,205,220,.22)` | 内部分隔线、控件边框 |
| `--text-primary` | `#EAF6FF` | 标题、主数值 |
| `--text-secondary` | `#BFD4E2` | 次要说明、标签（提亮一档，保证深蓝底上对比度 ≥ 4.5:1） |
| `--brand-cyan` | `#6FDCEA` | 主品牌色/强调色/图表主色 |
| `--brand-blue` | `#3E86B4` | 次级强调、渐变起色 |
| `--state-ok` | `#4FD69B` | 正常、达标 |
| `--state-warn` | `#F0B75A` | 预警、停机时长 |
| `--state-danger` | `#FF5D6C` | 异常、告警 |
| `--chart-1` | `#6FDCEA` | 图表系列 1（默认主色） |
| `--chart-2` | `#3E86B4` | 图表系列 2 |
| `--chart-3` | `#4FD69B` | 图表系列 3 |
| `--chart-4` | `#F0B75A` | 图表系列 4 |
| `--glow-primary` | `rgba(111,220,234,.5)` | 主色发光 |
| `--gradient-panel` | `linear-gradient(180deg,rgba(18,62,92,.35),rgba(12,50,76,.2))` | 控件/面板渐变 |

> 状态色浅底版（`-bg` / `-border`）按需用 `rgba(状态色, .14)` 派生，不单独设 hex。

### 1.2 字号阶梯（px）

| 层级 | 值 | 用途 |
|---|---|---|
| xs | 12 | 角标、辅助说明 |
| sm | 14 | 正文、标签、按钮 |
| md | 16 | 小标题、 emphasized 正文 |
| lg | 18 | 面板标题 |
| xl | 20 | 次级数值 |
| 2xl | 24 | 大数值 |
| 3xl | 28 | 关键 KPI 数字 |
| 4xl | 32 | 页面主标题 |

- 字重：400 常规 / 500 中等 / 600 强调 / 700 大屏 KPI 数字。
- 行高：正文 1.4，标题 1.2，大数字 1.1。
- **禁止**在业务样式中出现阶梯外的字号（如 12.5、17、19、22、26），统一就近归到上表。

### 1.3 间距 / 圆角 / 边框 / 阴影 / 动效 / 层级

| 类别 | 规范 |
|---|---|
| 间距 | 只用 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40；面板内边距 16（紧凑 12）；卡片 gutter 16 |
| 圆角 | 0（数据区）/ 2（面板）/ 4（控件、弹窗）；**禁止 ≥ 8**，科技风偏锐利 |
| 边框 | 面板 1px `--border-base`；内部分隔 1px `--border-soft`；不叠加多重边框 |
| 阴影 | 面板内阴影与浮层投影各一档；发光仅主色一档，禁止大面积泛光 |
| 动效 | hover 150ms、展开 250ms、浮层淡入 250ms；`ease` 缓动；禁止无限循环动画 |
| 层级 | 内容 1 / 悬浮菜单 10 / 弹窗 30 / 全局提示 40 |

## 第 2 章 面板（卡片）结构规范

| 项 | 规范 |
|---|---|
| 结构 | 面板 = 标题栏 + 内容区；标题栏固定 40px，内容区 `flex:1; min-height:0` 自适应填充 |
| 标题栏 | 字号 18 / 600；左内边距 16；左侧统一用一个菱形/竖条作为左上角标（全系统二选一，选定后不改） |
| 标题操作 | 右上角“详情”等次级操作用文字按钮，字号 14 / `--text-secondary`，hover 变主色 |
| 内容区 | padding 16（紧凑 12）；数据区不得写死高度，随面板高度自适应 |
| 面板间距 | 横纵 gutter 统一 16 |
| 边框/背景 | 统一 `--border-base` + `--bg-panel`，禁止各面板自带背景图 |
| 统一性 | 同类面板标题栏高度、标题字号、内边距、圆角、边框必须一致 |

## 第 3 章 图表基线（内联 SVG，无图表库）

| 项 | 标准 |
|---|---|
| 取色 | 折线/面积/仪表/柱统一从 `--chart-1 … --chart-4` 顺序取色，禁止随机色、彩虹色 |
| 折线 | 线宽 2，无填充或半透明填充 `--chart-1` 透明度 ≤ .16；拐点不加圆点除非表达离散值 |
| 仪表/进度 | 轨道用 `--border-soft` 或主色 .18 透明；值用 `--chart-1`；数值文字用 `--text-primary` |
| 网格/分割线 | 若绘制，用 `--border-soft`，透明度 ≤ .12 |
| 数值标签 | 字号 14；单位文字 12 `--text-secondary`，与数字贴近 |
| 空数据 | 统一显示“暂无数据”占位，禁止留白 |
| 反例 | 禁止 3D 效果、渐变堆叠、阴影滥用、图例压标题、缺单位、双轴无标识 |

## 第 4 章 控件规范

| 控件 | 规范 |
|---|---|
| 按钮 | 高 32（大屏用 36）/ 圆角 4 / 字号 14；主按钮 `--bg-panel-hover` + `--brand-cyan` 边框，次按钮 `--border-soft`；hover 主色；禁用态降低透明度 |
| 页签 Tab | 高 36 / 圆角 4 / 字号 15；选中态主色边框 + 内发光，未选中 `--text-secondary` |
| 下拉选择 | 高 34 / 圆角 4 / 边框 `--border-soft`；展开菜单底 `--bg-elevated`，项字号 14，hover 主色 |
| 文字按钮（详情） | 字号 14 / `--text-secondary`，hover 主色，无边框 |
| 弹窗 | 宽度按内容选 480/640/800/1200 档；标题栏 44，标题字号 18；内容 padding 12；遮罩 `--bg-mask`；点击遮罩或 ESC 关闭；内容超高时独立滚动 |
| 提示 Toast | 底部居中；字号 14；深色底 + 主色边框；约 2s 自动消失 |

---

## 第 5 章 文案规范

- 界面上禁止出现“示例”“示意图”“演示”“按钮未接入”“仅保存在本机”等制作说明式文字。
- 标题、标签、图例、单位使用产品面向用户的真实业务语言，简短、 unambiguous。
- 数值与单位之间留空格（如 `1360 kWh`、`42.5 kWh/件`），百分比紧贴数字（如 `98%`）。

## 第 6 章 自检清单（改造后逐页检查）

| 检查项 | 通过标准 |
|---|---|
| 硬编码色值 | 除 `:root` token 定义外，业务样式区裸 hex 命中数 = 0 |
| 字号 | 全部落在 12/14/16/18/20/24/28/32 阶梯 |
| 间距 | 全部为 4 的倍数 |
| 圆角 | 仅 2 或 4，无 ≥ 8 |
| 面板结构 | 标题栏 40px、标题 18/600、内边距 16、左上角标统一 |
| 图表取色 | 全部走 `--chart-*` 或 `--brand-cyan` |
| 文案 | 无制作说明式文字，单位规范 |
| 零乱码 | 文件无乱码、无 BOM |
| 交互 | 弹窗、下拉、Tab、按钮等原有交互不变 |
