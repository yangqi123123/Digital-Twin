## 1. 角色与目标

你是脉动智能产线大屏系统的前端实现工程师。任务：基于 **MES 智能生产制造平台** 与 **外部 IOT 物联网平台** 两套数据源，实现 **11 个工作站大屏**（屏 1 钢筋网片工作站生产屏 ～ 屏 11 顶板安装工作站生产屏）。每工位一屏，模块骨架统一、指标口径统一，工位之间仅按绑定工序替换差异化指标与工序步骤条。

**唯一目标**：把下列模块与指标按需求落地为只读大屏视图。业务 / 结果类指标取 MES，实时量测 / 设备运行类指标取 IOT；**不准混用来源，不准出现无来源指标，不准编造无点位的实时数值**。

### 1.1 边界约束（红线）

1. 工位大屏是**只读展示视图**：不提供报工、领料、质检录入、报修、领料发起等操作入口；操作回 MES 业务端完成。
2. 工位编号、名称、工序、班组等主数据从 MES「工厂设定-工作站配置 / 生产工序配置 / 班组资源配置」同步，**前端不写死工位清单**；未配置工位显示空态槽位。
3. 大屏与 IOT 点位统一以 **工作站编号** 作为关联主键；设备 / 点位未绑定工位编号的，不上屏。
4. 所有指标必须可追溯到来源标注（MES / IOT）；无法取数的模块按第 9 节空态兜底，不用 0 或假值填充。

1. 业务、计划、结果类（工单、任务、报工、完成率、人员、质量判定、物料状态、库存、报修闭环）→ **MES**。

### 3.1 业务逻辑闭环（每屏必须跑通）

```
M6 物料齐套（领料/配送/齐套率/缺料）
        │  齐套方可开工；缺料/延期配送 → M8 缺料类异常回挂
        ▼
M2/M4 任务接单（待生产任务、工单、当前工序、作业人员）
        │  未接单/停滞 → M8 未接单/停滞异常回挂
        ▼
M1/M3 作业执行（班组人员在岗、报工时间、产出趋势）
        │  报工异常/停滞 → M8 报工异常回挂
        ▼
M2 产出汇总（完成数量、在制、完成率）── M5 质量判定（待检/合格/不良/一次合格率/复检闭环）
        │                                            │  不合格/待复检 → 不良清单挂工单，复检闭环后转序
        ▼
   完工转序（当前工序推进至下一道）；M7 设备/参数过程保障；M8 超期、设备告警、未闭环异常全程回挂跟踪
```

**闭环校验要求**：任一任务在 M4 出现状态，必须能沿「M6 齐套 → M2 任务 → M3/M4 执行报工 → M5 质量 → 完工」追溯；任一异常（缺料、超期、设备故障、质检不合格）必须在 M8 有对应条目，并能回链到来源任务 / 工单 / 设备，不允许出现悬空告警。

## 5. 工序步骤条专项规则（M0 实现细则）

1. **节点来源**：步骤节点 = MES「生产工序配置」中绑定到本工位的工序，按工艺路线顺序排列；节点编号 + 名称均取主数据，不在前端硬编码工序名。
2. **状态映射**：
   - 工单「已完成」且该工序已报工 → 节点 **已完成**（绿）。
   - 工单「生产中」且当前工序命中本节点 → 节点 **进行中**（高亮蓝/脉冲）。
   - 工单「待接单 / 待生产」 → 节点 **未开始**（灰）。
   - 工单「已暂停」 → 节点 **已暂停**（灰蓝），显示暂停原因。
   - 工单「异常」或质检不合格 / 复检未闭环 → 节点 **异常**（红）。
3. **推进约束**：前序节点未完成（含质检未闭环）时，后续节点不得置为进行中；步骤条状态与 M4 当前工序、M5 闭环状态三方一致。
4. **指导书挂载**：节点下展示该工序在 MES 上传的指导书附件名与类型；附件未上传显示「未上传作业指导书」。前端只做文件名展示 / 只读预览，不解析、不补写指导书内的操作步骤条目。
5. **多任务**：同一工位存在多张工单时，步骤条以生产中工单为主线展示；其余工单工序进度在 M4 明细列体现。
6. **刷新**：工序主数据 5 min 刷新；节点状态随报工 30 s 刷新。
