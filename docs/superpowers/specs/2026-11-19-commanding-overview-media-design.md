# 厂区总览媒体与运营卡片改造设计

日期：2026-11-19
目标页面：`Commanding _screens/pages/指挥大屏.html`

## 1. 产品事实与范围

- 用户要在现有「厂区总览」静态原型上完成四项局部改造，不重做页面，不改变三栏结构与既有业务数据。
- 页面为 2600 × 800 设计画布等比缩放，单文件内联 CSS 与原生 JavaScript；不得引入框架、组件库、图表库或构建工具。
- 首屏主角仍是中央厂区三维总览；左栏主动作是查看工作站与任务媒体，监控卡的主动作是全屏查看单张图片。
- 素材来自 `visit_screens/assets/images/墙板拼装.mp4`、`s1.jpg`、`s2.jpg`、`s3.jpg`，第四路监控复用 `s1.jpg`。
- 当前目录不是 Git 仓库，因此设计与实施均不产生提交记录。

## 2. 已确认方案

采用「媒体下方保留信息」方案：当前任务区左侧显示图片、右侧显示墙板拼装视频，下方独立保留任务名称、任务编号、产量与进度。相比信息覆盖视频，该方案不遮挡画面；相比纯媒体方案，该方案保留关键任务信息。默认工作站与任务同步调整为 P03 墙板拼装，确保标题和视频内容一致。

## 3. 布局与交互

### 3.1 工作站

- 默认选中 `P03 墙板拼装`，原图片区域改为自动播放、静音、循环、内联播放的视频。
- 保留工作站下拉切换；P03 使用视频，其他工作站沿用现有图片，避免名称与内容不一致。
- 视频使用现有墙板拼装图片作为封面，加载失败时显示封面，不影响其他控件。
- 「数字孪生」按钮保留原详情弹窗行为。

### 3.2 当前任务

- 媒体行保持左图右视频：左侧沿用现有任务现场图片，右侧使用同一墙板拼装视频。
- 媒体下方新增紧凑任务信息栏，保留 `P03 墙板拼装`、`MP20261019006`、`36 / 110` 和 `33%`，不改数据口径。
- 适当增加当前任务面板高度，等量减少工位监控面板的剩余高度，左栏总高度不变。
- 保留「任务详情 / 设备详情 / 设备定位」三个按钮与既有弹窗。
- 工作站切换时任务名称同步；P03 显示视频，其他工作站右侧显示对应静态图。

### 3.3 工位监控

- 四路图片依次为 `s1.jpg`、`s2.jpg`、`s3.jpg`、`s1.jpg`。
- 每路保留 CAM 编号，并在图片下方提供明确的「全屏」按钮；点击图片也可进入同一全屏状态。
- 优先使用浏览器原生 Fullscreen API 全屏展示单张图片；不支持时在现有遮罩弹窗中等比放大展示。原生全屏由 ESC 或「退出全屏」按钮显式退出，弹窗回退由 ESC、关闭按钮或遮罩退出。
- 全屏图片保持完整比例，不拉伸、不裁切。

### 3.4 五个运营模块

- 综合生产、设备运行、质量管控、物流调度、低碳安全保留现有数据、图表类型、详情入口和两行加一通栏布局。
- 视觉方向为「克制的工业调度仪表盘」：统一标题栏、细分隔线、数据层级与图表轨道，强化主 KPI 和异常信息，降低装饰性泛光。
- 复用页面现有 `:root` 色值与项目字号、间距、圆角规范；新增颜色只作为 token 派生，业务样式不新增裸 hex。
- 用轻量图表分区底、顶部状态线和 KPI 标签建立一致性；KPI 数字区使用透明底，不叠加额外背景。只添加 150ms hover 反馈，不增加循环动画。

## 4. 资产与实现边界

- 将视频与三张监控图片复制到 `Commanding _screens/assets/images/`，让指挥大屏资产自包含；源文件保持不变。
- 仅修改目标 HTML 与新增上述资产、设计及实施文档，不重构中央模型、时钟、漫游、视角保存等无关逻辑。
- 两个视频元素使用同一本地视频 URL，均设置 `muted autoplay loop playsinline`；不引入额外视频播放器。

## 5. 验收标准

1. 默认工作站和任务均为 P03 墙板拼装，两处视频可自动静音循环播放，其他工作站切换仍有效。
2. 当前任务左图右视频，下方任务文字完整，无重叠、裁切；三个任务按钮行为不变。
3. 四路监控图片正确，四路均有全屏按钮，点击后能查看完整大图并可退出。
4. 五个运营模块数据不变、布局整齐、视觉层级一致，详情按钮仍打开原弹窗。
5. 在 1920 × 590 目标视口检查实际截图，并检查 100% 与 200% 缩放关键区域；无横向溢出、文字遮挡或乱码。
6. 页面无新增外部依赖；业务样式无新增裸 hex，字号、间距、圆角符合现有规范。
